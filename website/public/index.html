Three keys. Three wheels.Tři klávesy. Tři kola.

Drag a file from File Explorer, the desktop, your browser or an e-mail. While you're dragging, tap a key and the wheel appears under your cursor. Drop on a slice. The result lands next to the original, and the original is never touched. Táhněte soubor z Průzkumníku, plochy, prohlížeče nebo e-mailu. Během tažení ťukněte na klávesu a pod kurzorem se objeví kolo. Pusťte ho na výseč. Výsledek se uloží vedle originálu, originál zůstane netknutý.

Updates itselfAktualizuje se sám

When a new version is out, FileAction offers it; one click installs it after a checksum check. FFmpeg (video, audio) and Pandoc (documents) download the first time you need them; Office formats like DOC, PPTX and ODS need LibreOffice installed.Když vyjde nová verze, FileAction ji nabídne a jedním kliknutím ji po ověření otisku nainstaluje. FFmpeg (video, zvuk) a Pandoc (dokumenty) se stáhnou, až je poprvé budete potřebovat; formáty Office jako DOC, PPTX a ODS potřebují nainstalovaný LibreOffice.

On Linux tooI na Linuxu

The same wheel as a drop zone you drag files onto, a FileAction… item in the right-click menu of Dolphin and Nemo (in Nautilus under Scripts), and a command line for scripts and keyboard shortcuts. Stejné kolo jako zóna, na kterou soubory přetáhnete, položka FileAction… v pravém tlačítku v Dolphinu a Nemu (v Nautilu pod Skripty), a příkazová řádka pro skripty a klávesové zkratky.

Arch Linux: download the PKGBUILD and run makepkg -si. Everyone else: unpack the tarball and run it. No .NET needed. Arch Linux: stáhněte PKGBUILD a spusťte makepkg -si. Ostatní: rozbalte archiv a spusťte. .NET není potřeba. 

# the wheel for this file
$ fileaction photo.heic

# what can be done with it
$ fileaction list photo.heic

# do it, no window
$ fileaction run image.to.webp *.heic
✓ photo.webp

$ fileaction run video.trim clip.mov \
    --param start=0:10 --param end=0:25

FAQ

Is it really free?Je to opravdu zdarma?

Yes. FileAction is open source under the MIT license. No ads, no account, no "pro" version.Ano. FileAction je open source pod licencí MIT. Žádné reklamy, žádný účet, žádná „pro“ verze.

Does it upload my files anywhere?Nahrává moje soubory někam?

No. Every conversion runs on your computer. The only network requests are the update check (it asks GitHub for the latest version), the one-time download of FFmpeg or Pandoc when you first need them, a link or picture you drag from a web page (FileAction downloads that one file), and feedback, which is sent only when you write some and click Send.Ne. Každý převod běží na vašem počítači. Jediné síťové požadavky jsou kontrola aktualizací (dotaz na GitHub na nejnovější verzi), jednorázové stažení FFmpeg nebo Pandoc, když je poprvé potřebujete, odkaz nebo obrázek přetažený z webové stránky (FileAction stáhne právě ten soubor) a zpětná vazba, která odejde jen tehdy, když ji napíšete a kliknete na Odeslat.

Why doesn't the drag-and-tap gesture work on Linux?Proč na Linuxu nefunguje gesto „táhnu a ťuknu“?

Linux desktops (Wayland in particular) don't let apps watch the keyboard and mouse of other programs. That's a good thing for security, so on Linux you drop files onto the wheel, use the right-click menu or the command line instead.Linuxová prostředí (hlavně Wayland) nedovolí aplikacím sledovat klávesnici a myš jiných programů. Pro bezpečnost je to dobře, takže na Linuxu soubory pustíte přímo na kolo, použijete pravé tlačítko nebo příkazovou řádku.
